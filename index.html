Как рассчитывается время взлома?
Метод расчёта: Чистый brute-force (полный перебор)

Параметры:

  • Скорость: 6.7 миллиардов попыток в секунду
  • Комбинации: размер_наборадлина_пароля
  • Средний случай: пароль найден после перебора 50% комбинаций

Формула:

Время = (комбинации / 6.7×10⁹) / 2 секунд

Размер набора символов:

  • Только строчные (a-z): 26 символов
  • Строчные + заглавные (a-z, A-Z): 52 символа
  • Буквы + цифры: 62 символа
  • Буквы + цифры + спецсимволы: 62+ символов

⚠️ Это теоретическое время для идеального brute-force атаки. В реальности взломщики используют словари, паттерны и утечки данных, что может значительно ускорить процесс для слабых паролей.

Как рассчитывается энтропия пароля?
Формула Шеннона: H = -Σ(pi × log2(pi))

Где:

  • H — энтропия на один символ (в битах)
  • pi — вероятность i-го символа (частота / длина пароля)
  • Σ — сумма по всем уникальным символам

Полная энтропия:

Общая энтропия = H × длина пароля
Минимальный порог = 1 бит на символ

Примеры:

  • "aaaaaaaa" → 8 бит (все символы одинаковые)
  • "password" → ~23 бита (умеренное разнообразие)
  • "aB3@xK9#" → ~52 бита (высокое разнообразие)

💡 Энтропия измеряет информационное содержание на основе реального распределения символов в пароле, а не теоретического размера алфавита.

Советы по безопасности

Используйте фразы
Создайте пароль из первых букв любимой фразы или песни. Например: "Я родился в 1990 году в Москве!" → "Яр@1990гвМ!"
Менеджер паролей
Используйте надежные менеджеры паролей (1Password, Bitwarden, KeePass) для хранения и генерации уникальных паролей.
2FA аутентификация
Включите двухфакторную аутентификацию везде, где это возможно. Это добавляет дополнительный уровень защиты.
Уникальные пароли
Никогда не используйте один пароль для разных сайтов. Утечка на одном сайте может скомпрометировать все аккаунты.
Регулярная смена
Меняйте пароли для критически важных сервисов каждые 3-6 месяцев, особенно для банковских и почтовых аккаунтов.
Избегайте личного
Не используйте личную информацию: даты рождения, имена близких, клички питомцев, адреса.

О запоминаемости парольных фраз

Легче запомнить: Парольные фразы состоят из обычных слов, которые наш мозг легко запоминает.

Высокая безопасность: 4-5 случайных слов обеспечивают очень высокий уровень защиты.

Примеры фраз:

  • correct-horse-battery-staple
  • Синий_Кот_Прыгает_Весело

Как использовать генератор

Оптимальная длина
Для большинства случаев достаточно 16 символов. Для критически важных аккаунтов используйте 20+ символов.
Баланс безопасности
Используйте все типы символов для максимальной энтропии. Каждый дополнительный набор значительно усложняет взлом.
Сохранение паролей
Никогда не сохраняйте пароли в текстовых файлах или браузере. Используйте специальные менеджеры паролей.

О хешировании

Хеширование - это односторонняя функция преобразования данных в уникальную строку фиксированной длины.

  • MD5 - 128 бит (устарел, не рекомендуется для безопасности)
  • SHA-1 - 160 бит (устарел, не рекомендуется)
  • SHA-256 - 256 бит (рекомендуется, широко используется)
  • SHA-512 - 512 бит (высокая безопасность)

Хеши не являются шифрованием и не могут быть декодированы обратно!

Применение хеширования

Проверка целостности
Хеши используются для проверки целостности файлов. Любое изменение файла приводит к полностью другому хешу.
Хранение паролей
Сервисы хранят хеши паролей, а не сами пароли. При входе ваш пароль хешируется и сравнивается с сохраненным хешем.
Цифровые подписи
Хеши являются основой для создания цифровых подписей и проверки подлинности документов.
Не используйте MD5
MD5 и SHA-1 считаются устаревшими и уязвимыми. Для критически важных задач используйте SHA-256 или выше.
Соль для паролей
При хешировании паролей всегда используйте "соль" - случайные данные, добавляемые к паролю перед хешированием.
Уникальность хешей
Вероятность коллизии (двух разных входов с одинаковым хешем) крайне мала для современных алгоритмов.
